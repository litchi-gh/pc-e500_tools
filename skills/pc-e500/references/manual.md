# 説明書（TXT）

プログラムができたら、遊ぶ人、使う人のための短い説明書を 1 つ作る。**最後の `e500 bin` と確認が終わってから書く**（アドレスや大きさが変わるため）。

- 場所と名前: ソースの隣に `名前_MANUAL.txt`（`truck.asm` なら `TRUCK_MANUAL.txt`）。UTF-8 の普通のテキスト（Markdown の記号を使わない）。1 行は全角 38 文字くらい、全体で 1〜2 画面。
- 直したら説明書も直す。利用者が書いた同じ名前のファイルは上書きせず、名前を変える。
- **数と行は `e500 bin prog.asm` の出力を写す**（`--json` なら `file` `bytes` `origin` `end` `reserve` `load` `call`）。自分で計算しない。
- 操作、画面、得点の決まりは、**プログラムにある通りに書く**。キーは `e500 run --keys` で効くことを確かめたものだけ。
- **ROM のバージョンと「確かめたこと」は書かない**（確認の結果は、会話の報告に書く）。一部の機種でしか動かない命令を使ったときは、「機種」を、動く機種の名前（PC-E500S、PC-U6000、PC-E650 など）にする。
- 個人の名前、PC のパスを書かない。利用者が英語なら英語で書く。

## 機械語のとき

`origin` は先頭アドレス（= `ORG`）。**エリアの確保は `reserve` の `POKE` の 1 行だけを書く**。今の先頭を `PEEK` で確かめる手順は書かない。`{ }` を埋める。

```text
{プログラムの名前}
{何をするプログラムか、1〜2 行}

■ 要るもの
  機種      PC-E500 シリーズ
  RAM       {必要な大きさ}（機械語エリア {大きさ} バイト）
  ファイル  {TRUCK.BIN}（{bytes} バイト、{origin}〜{end}）

■ 1. ファイルを本体から読めるようにする
  {TRUCK.BIN} を、CE-140F（互換機の SD カードなど）のディスクに
  入れます。下の X: はそのドライブです。RAM カードなどに入れた
  ときは、E: などに読み替えます。

■ 2. 機械語エリアを確保する（最初の 1 回だけ）
  RUN モードで、次を打ちます。

    {reserve}

  メインメニューになります（正常です）。BASIC キーで戻ります。

■ 3. 読み込んで動かす
    {load}
    {call}

  次からは {call} だけで動きます。BASIC のプログラムから動かすには、
  {load} と {call} を 2 行に書きます（2 は書けません）。

■ 操作
  {キー}  {働き}
  ON/BRK  {やめて BASIC に戻る、など}

■ 画面と決まり
  {画面の見方、得点、終わる条件、計算の範囲など}

■ 片付け
  機械語エリアを BASIC に返すには（中身は使えなくなります。ほかの
  機械語を入れているときは打たないでください）、次を打ち、BASIC
  キーで戻ります。

    POKE &HBFE03,&H1A,&HFD,&H0B,&H00,&H00,&H00:CALL &HFFFD8

■ 困ったとき
  File not found            名前かドライブが違います。FILES "X:" で見ます
  CALL の後、メニューになる  確保と LOAD M をやり直し、CALL の数を確かめます
  固まる                    ON/BRK で戻らなければ RESET を押します
                            （データを消すかの問いには、消さないを選びます）
  オールリセットした        2 からやり直します
```

- エリアの大きさ（バイト）は `&HBFC00 − origin`。
- プログラムの中で確保するものではない（確保の `CALL` はメインメニューに移り、BASIC が止まる）。
- `bin` が「機械語エリアではありません」と言ったら、`reserve` はない。`ORG` を直す。
- BASIC から呼ぶルーチンなら、「操作」の代わりに、値の渡し方（どのアドレスに `POKE` し、どこを `PEEK` するか）と BASIC の例を書く。
- 確保、読み込み、実行の 3 行は、エミュレータでは `e500 run` がしている。説明書の行が動くかは、`e500 bin` が出した行をそのまま写していることで確かめる。

## BASIC のとき

実機に送るファイルは `e500 bin prog.bas -o {別の名前}.BAS` で作る（入力と違う名前にする）。

```text
{プログラムの名前}
{何をするプログラムか、1〜2 行}

■ 要るもの
  機種      PC-E500 シリーズ
  ファイル  {OUT.BAS}（{bytes} バイト）

■ 動かし方
  {OUT.BAS} を、CE-140F（互換機の SD カードなど）のディスクに入れ、
  RUN モードで打ちます。今あるプログラムは消えるので、要るものは
  先に SAVE します。

    LOAD "X:{OUT.BAS}"
    RUN

  本体に残すには  SAVE "E:{名前}.BAS"  （E: は RAM ディスク。
  使えるように初期化してあるとき）

■ 操作
  {キー}  {働き}
  ON/BRK  止めます（もう一度動かすには RUN）

■ 画面と決まり
  {画面の見方、得点、入力できる値、保存するファイルなど}

■ 変えるところ
  {行番号}  {DATA や数の意味}

■ 困ったとき
  File not found   名前かドライブが違います。FILES "X:" で見ます
```

BASIC と機械語の両方を使うときは、機械語の形に、BASIC を `LOAD` して `RUN` する行を 3 の後に足す。

## 書いた後に

1. `{` と `}` が残っていない。
2. ファイル名、アドレス、3 行が、今の `e500 bin` の出力と同じ。
3. 「操作」のキーが、プログラムの読んでいるキーとすべて合っている。
