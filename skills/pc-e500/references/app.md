# アプリを作る

ふつうのアプリ（計算、換算、一覧、記録、ツール）の作り方。ゲームは [game.md](game.md)。

| ひな形 | 言語 | 入っているもの |
|---|---|---|
| `e500 new 名前 --kind basicapp` | BASIC | メニュー、`INPUT`、一覧、合計、`E:` への保存と読み込み、エラー処理、テスト |
| `e500 new 名前 --kind app` | 機械語 | メニュー、1 行入力（BS、ON/BRK）、10 進と 16 進の変換、文字の表示、テスト |

作るときは、まず画面（40 桁 × 4 行）の案を利用者に見せ、入力の項目、保存するか、件数を確かめる。

## 形

1. **メニュー** → 選ぶ → **入力** → **計算** → **結果** → キーを待つ → メニューへ戻る。`Q` か ON/BRK で終わる道を必ず作る。
2. 計算、変換、検査は、画面とキーを使わないサブルーチンに分ける。テストで 1 つずつ呼べる。
3. 入力は必ず検査する: 空、数でない、範囲の外、長すぎる、0 での割り算、件数の上限。

## 画面

- 40 桁 × 4 行。1 行目は題や件数、2〜3 行目は中身、4 行目は案内か入力。
- 一覧は 3 行ずつ出して、キーを待ってから消す。数は右、名前は左にそろえる（`LEFT$(A$+空白,20)`、`RIGHT$("     "+STR$ N,6)`）。
- BASIC で最後の行に `;` なしの `PRINT` をするとスクロールする。プロンプトに戻ると画面の下が流れるので、結果のあとはキーを待つ。
- 日本語は半角カナ（ROM が英語の機種では別の文字になる）。英数字なら全機種で同じ。

## BASIC の部品

```basic
100 K$=INKEY$:IF K$="" THEN 100
110 K=VAL K$:IF K<1 OR K>5 THEN 100
120 ON K GOSUB 200,300,400,500,600
200 A$="":INPUT "NAME=";A$:IF A$="" THEN RETURN
210 RETURN
```

- `INPUT` は、ENTER だけだと**前の値のまま**。先に空にする。数は文字で受けて検査してから `VAL` する（式やエラーを受けない）。
- `PRINT #` で書いた文字列の `,` と `"` は、`INPUT #` で区切りになる。書く前に置き換える。読み込みは別の配列に読み、全部読めてから入れ替える。
- `RUN` の ENTER や前のキーを拾わないように、待つ前に `IF INKEY$<>"" THEN 自分の行`。
- 表、単価、問題、単位の倍率、メニューの文言は、最後の `DATA` にまとめて `RESTORE 行` と `READ` で読む（[basic.md](basic.md) の「データは DATA に寄せる」）。
- 配列は `DIM A$(50)*16`（文字数を決める）。`CLEAR` は始めに 1 回。`GOSUB` の中で `CLEAR` しない。
- ファイル: `OPEN "E:NAME" FOR OUTPUT AS #1`、`PRINT #1,A$`、`INPUT #1,A$`、`CLOSE`。`E:` は利用者が `INIT "E:8K"` を直接打って作る。`ON ERROR GOTO` で「ない」「いっぱい」を受け、`RESUME` で戻り、`ON ERROR GOTO 0` で戻す。
- 印刷: `LPRINT`（CE-126P など）。シリアル: `OPEN "COM:9600,N,8,1,A,C,&H1A,N,N" AS #1`。
- 変数 `A`〜`Z` は `RUN` で消えない。始めに値を入れる。

## 機械語の部品

ひな形 `app` のルーチンを使う。どれも IOCS だけで、割り込みは止めない。

| 呼ぶもの | 働き |
|---|---|
| `show` | 画面を消して、`X` から 0 で終わる文字列を 1 行ずつ出す |
| `print` | `X` の文字列を `(BL)` 桁、`(BH)` 行に出す |
| `get_key` | キーを待つ（`A` = 文字。`KEY_ENTER` などは `keycode.inc`） |
| `input` | 1 行入力を `line` に置く。ON/BRK なら C = 1 |
| `to_num`、`hex_num` | 文字 → `I`。数でなければ C = 1 |
| `to_dec`、`to_hex` | `I` → 文字 |

- 自分の変数は内部 RAM の 20h〜（IOCS は D4h〜DFh を使う）か、プログラムの後ろの `DS`。
- 終わりは、画面を消して `RC`、`RETF`。
- 乗算、除算、10 進演算、並べ替えは `docs/manual/20_RECIPES.md`、BCD の計算は `Samples/Assembler/Basics/bcd.asm`。
- ファイルは FCS、印刷とシリアルは IOCS（`e500 help DEV_PRN`、`docs/analysis/11_IOCS.md`）。長い計算の間は、ON/BRK を見る（`TEST ($FF),$08`）。

## 確かめ方

- `e500 test` に、計算の端の値（0、負、最大、空、桁あふれ）、メニュー、1 つの操作の最初から最後まで、間違った入力、終わり方を入れる。
- `e500 run … --keys` で一通り操作し、画面の文字を見る。`INPUT` には `--type "値\n"`。
- 保存するものは、保存 → `Q` → もう一度 `RUN` → 読み込みまで試す。`E:` がないときの動きも見る。
- `--rom 2.2`、`--rom 8.5` などで、ほかの機種でも動くかを見る。
