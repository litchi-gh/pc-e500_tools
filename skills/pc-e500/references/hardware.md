# ハードウェアの要点

名前は `INCLUDE "hardware.inc"` にある（`e500 help KOL` などで引ける）。くわしくは各節の終わりの資料。

## 機種

| 機種 | ROM | 内蔵 RAM | 画面 | 構造化 BASIC |
|---|---|---|---|---|
| PC-1480U | 2.1 | 32 KB | 日本語 | − |
| PC-E500 | 2.2、3.2、7.2 / 5.3、6.3、7.3 | 32 KB | 日本語 / 英語 | − |
| PC-E500PJ | 6.2 | 32 KB | 日本語 | − |
| PC-E550、PC-1490UII | 7.5、6.4 | 64 KB | 日本語 | − |
| PC-E500S | 8.3 | 32 KB | 英語 | あり |
| PC-U6000、PC-E650 | 8.4、8.5 | 64 KB | 日本語 | あり |

- 共通: CPU SC62015（ESR-L）、240 × 32 ドット、公開エントリ、機械語エリア、コネクタ。`PEEK &HFFFF0` が改訂（7 など）、`PEEK &HFFFF1` が機種コード（2 = 日本語の PC-E500、3 = 英語）。
- どの機種でも動かすには、RAM 32 KB に収め、公開エントリだけを呼び、構造化の命令、カナ、`¥`、`G:` に頼らない。`--rom 2.2`、`--rom 8.5` などで試す。
- 資料: `docs/analysis/29_MODELS.md`、`docs/analysis/24_ROM_VERSIONS_BASIC.md`、`docs/analysis/26_ROM_VERSIONS_SYSTEM.md`

## クロックと時間

- 主クロック 2.304 MHz。**1 サイクル = 1.30 µs（768,000 サイクル/秒）**。命令のサイクルは `e500 help 命令`。
- 速いタイマ 16 ms（`SCR` ビット 1 = 0 で 4 ms）、遅いタイマ約 0.5 秒。`HALT` 中は速いタイマが止まる。

## 外部メモリ（20 ビット、1 MB）

| アドレス | 内容 |
|---|---|
| `00000h`〜`03FFFh`、`08000h`〜`0BFFFh` | LCD コントローラ（`2000h` 台を使う） |
| `10000h`〜`1FFFFh` | ROM カード |
| `20000h`〜`3FFFFh` | 拡張 ROM（PC-E500S、PC-E650、PC-U6000） |
| `40000h`〜`7FFFFh` | RAM カード（`40000h` から） |
| `B8000h`〜`BFFFFh`（64 KB の機種は `B0000h`〜） | 内蔵 RAM |
| 〜`BFBFFh` | **機械語エリア**（下限は `[BFD1Ah]`、3 バイト。確保しないと BASIC が使う） |
| `BFC00h`〜`BFFFFh` | システムの作業域 |
| `C0000h`〜`FFFFFh` | ROM |

- 公開エントリ: `FFFE8h` IOCS、`FFFE4h` FCS、`FFFD8h`（作業域の大きさ。機械語エリアの確保）、`FFFDCh`（BASIC から IOCS）。ほかの ROM のアドレスはバージョンで違う。
- 資料: `docs/analysis/03_MEMORY.md`「システムアドレス」、`docs/analysis/05_CARD_SLOT.md`、`docs/analysis/09_CIRCUIT.md`「チップセレクト」

## 内部 RAM（256 バイト、`(n)`）

| アドレス | 内容 |
|---|---|
| `00h`〜`C9h` | 作業用。ROM も使うので、退避して戻す |
| `CAh`〜`D3h`、`E0h`〜`EBh` | システムのポインタ。触らない |
| `D4h`〜`DFh` | IOCS の引数（BL BH CL CH DL DH SI DI） |
| `ECh`〜`EEh` | BP、PX、PY。変えたら戻す |
| `F0h`、`F1h` | KOL、KOH: キーの列。**KOH の上位 4 ビットはシリアルの線（RS RR ER PRQ）なので `AND` / `OR` で変える** |
| `F2h` | KI: 押されているキーの行（読むだけ） |
| `F3h`、`F4h` / `F5h`、`F6h` | E ポートの出力 / 入力（11 ピン、15 ピン、電源の制御） |
| `F7h`〜`FAh` | UART: UCR、USR、RXD、TXD |
| `FBh`、`FCh` | IMR（許可。ビット 7 = 全体）、ISR（要因） |
| `FDh` | SCR: ビット 6〜4 ブザー、1 と 2 タイマの周期、3 表示電源 |
| `FEh` | LCC: ビット 7〜3 コントラスト（値 × 8） |
| `FFh` | SSR（読むだけ）: ビット 3 = ON/BRK が押されている |

`EFh`（AMC）と `F0h` から上は、書くと機器が動く。書く前に資料を読む。資料: `docs/analysis/02_CPU.md`「内部 RAM」「ポート」「UART」「システムのレジスタ」

## 液晶（240 × 32、HD61202 × 2）

| | コントローラ A（中央） | コントローラ B（両端） | 両方へ |
|---|---|---|---|
| 命令 | `2008h` | `2004h` | `2000h` |
| 状態（ビット 7 = BUSY） | `2009h` | `2005h` | − |
| データを書く | `200Ah` | `2006h` | `2002h` |
| データを読む（1 回目は空読み） | `200Bh` | `2007h` | − |

命令: `3Fh`/`3Eh` 表示 ON/OFF、`C0h+L` 開始ライン（0〜63）、`B8h+p` ページ（0〜7）、`40h+y` Y アドレス（0〜63）。データは縦 8 ドット（**ビット 0 が上**）で、書くと Y が 1 進む。

| x | コントローラ | ページ | Y アドレス |
|---|---|---|---|
| 0〜63 | B | y ÷ 8 | x |
| 64〜119 | A | y ÷ 8 | x − 64 |
| 120〜175 | A | 4 + y ÷ 8 | 175 − x（**右から左**） |
| 176〜239 | B | 4 + y ÷ 8 | 239 − x（**右から左**） |

- BUSY = 0 を待ってから書く。始めに開始ライン 0（`C0h` を `2000h` へ）を書く（BASIC のスクロールで変わっている）。ROM は遅いタイマごとに開始ラインを書き直すので、直接描くときは割り込みを止める。
- A の Y = 56〜63 の一部は表示シンボル（BUSY、RUN など）。全部消すとシンボルも消える。
- 直接書くより、`screen.inc`（仮想画面）か IOCS（`SCRN_*`）を使うと間違えない。資料: `docs/analysis/04_LCD.md`

## キー

- 行列を直接読むとき: `KOL`/`KOH` に 1 列だけ 1 を立て、`NOP` を 1 つ置き、`KI` を読む。読み終わったら `KOL` = 0、`AND (KOH),$F0`。

| キー | 列 | 行（KI のビット） |
|---|---|---|
| ▶ / RETURN | KO4（KOL 10h） | 6 / 7 |
| ▲ / ◀ | KO3（KOL 08h） | 6 / 7 |
| SPACE / ▼ | KO2（KOL 04h） | 6 / 7 |
| Z | KO0（KOL 01h） | 5 |
| ON/BRK | KO11（KOH 08h） | 1 |

- 割り込みの中でも、ON/BRK は `TEST ($FF),$08`。同時押しを見るなら `pad.inc`（`pad_read`）。
- IOCS: `KYBD_READ`（文字。`keycode.inc` の `KEY_*`）、`KYBD_MATRIX` / `KYBD_PEEK`（行列コード `MTX_*`）。
- BASIC の `INKEY$`: 矢印は右 0Eh、左 0Fh、上 04h、下 05h、RETURN 0Dh。
- 資料: `docs/analysis/11_IOCS.md`「行列コードと、文字への変換表」、`docs/analysis/10_SYSTEM.md`「キー入力の流れ」

## 割り込みとタイマ

- 要因のビット（IMR、ISR）: 0 速いタイマ、1 遅いタイマ、2 キー、3 ON、4 送信、5 受信、6 外部（電池）、7 全体の許可（IMR だけ）。ISR は 1 ビットなので、2 回起きても 1 回。
- RAM のベクタ: `BFCC6h` から 3 バイトずつ、ビット 0〜7 の順。書き換えるなら元の値を保存し、最後に元の処理へ `JPF`。自分の処理は短く、使うレジスタと内部 RAM を戻し、`RETF` で終える。終わるときに元へ戻す。
- 割り込みを止める: `PUSHU IMR` 〜 `POPU IMR`。長く止めると、時計、キー、シリアルの受信が遅れる。
- 資料: `docs/analysis/10_SYSTEM.md`「割り込み」「タイマ」

## 音

- `SCR` ビット 6〜4: `AND (SCR),BZ_OFF` してから `OR (SCR),BZ_2K`（20h）か `BZ_4K`（30h）で鳴り続け、`AND` で止まる。それ以外の高さは、`OR ($FD),$10` と `AND ($FD),$8F` を自分の周期で切り替える。
- BASIC の `BEEP n,P,D`: 1 周期 = 270 + 12 × P サイクル、D は周期の数。P = (768000 ÷ 周波数 − 270) ÷ 12（440 Hz は 123）。
- 資料: `docs/analysis/10_SYSTEM.md`「システム制御」「音（BEEP）」

## 文字の形

1 文字 6 バイト（縦 8 ドット、ビット 0 が上）。先頭は `[BFC90h]`（20h〜7Fh）、`[BFC8Ah]`（80h〜9Fh）、`[BFC93h]`（A0h〜DFh、半角カナ）、`[BFC8Dh]`（E0h〜）の 3 バイトのポインタから読む。資料: `docs/analysis/13_FONT.md`

## シリアル（15 ピン）

- 信号は CMOS レベル。**RS-232C に直結すると壊れる**（レベルコンバータが要る）。2 SD（TXD）、3 RD（RXD）、4 RS、5 CS、7 SG、8 CD、11 RR、14 ER、10 と 13 VC。
- UCR（F7h）: ビット 6〜4 速さ（1 = 300、2 = 600、3 = 1200、4 = 2400、5 = 4800、6 = 9600、7 = 19200 bps）、3〜2 パリティ（00 偶数、01 奇数、1x なし）、1 = 7 ビット、0 = ストップ 2。9600 / 偶数 / 8 / 1 は 60h。
- USR（F8h）: ビット 5 受信あり、3 送信の空き、2〜0 エラー。送るなら `TEST ($F8),$08` で空きを待って `MV ($FA),A`。
- BASIC は `OPEN "COM:9600,N,8,1,A,C,&H1A,N,N" AS #1`。資料: `docs/analysis/07_PORT_15PIN.md`

## 11 ピン（テープ、プリンタ、ディスク）

1 MT2、2 VCC（+）、3 GND（−）、4 BUSY（E6、出力）、5 DOUT（E10、出力）、6 XIN（CI、テープの入力）、7 XOUT（CO、テープとブザー）、8 DIN（E11、入力）、9 ACK（E7、入力）、10 IO2（E9）、11 IO1（E8）。E ポートの出力は `F3h`（E0〜7）、`F4h`（E8〜15）。**E3、E4 は電池電圧と表示電源の制御なので変えない**（`AND` / `OR` で目的のビットだけ）。資料: `docs/analysis/06_PORT_11PIN.md`、`docs/analysis/16_PERIPHERALS.md`

## RAM カードと電源

- RAM カードは `40000h` から（8 KB 〜 256 KB）。BASIC では `S2:`、RAM ディスク `E:` `F:`。`MEM$="S2"` でプログラムの置き場所が変わるので、機械語は内蔵 RAM に置く。資料: `docs/analysis/05_CARD_SLOT.md`
- 自動電源オフ: 約 10 分（`BFCBCh`、2 バイト、約 0.5 秒単位）。割り込みを止めたゲームの間は働かない。
