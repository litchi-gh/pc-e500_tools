# Change Log

## 0.2.0

- PC-E500 アセンブリ（`e500asm` 記法、`.asm` / `.inc` / `.e500asm`）のシンタックスハイライトと診断を追加
- 診断エンジンは `E500Assembler.Core` の TypeScript 移植（命令エンコード、PRE 自動生成、前方参照、`INCLUDE` / `INCBIN`、値の範囲・分岐距離・出力重複の検査）
- 「PC-E500 アセンブリとして開く」「e500asm でアセンブル」コマンドと `pocketAsm.*` 設定

## 0.1.1

- 任意のテキストファイルを「Pocket BASIC として開く」コマンド
- デバッグ開始時にサンプルを自動表示
