# Change Log

## 0.2.0

- INCLUDE ファイル `screen_part.inc` を追加した。仮想画面の四角い一部（左端、幅、行）だけを LCD に送る。`screen.inc` が INCLUDE しているので、`screen.inc` を使っていればそのまま呼べる。仮想画面を自分で持つプログラムは、このファイルだけを INCLUDE できる
- INCLUDE ファイル `gray.inc` を追加した。ドットを速く点滅させて、白と黒の間に灰色を 2 段出す（4 階調）。絵、キャラクタ、点を描ける。サンプル `Samples/Assembler/GrayDemo`
- `game.inc` の `game_end`、`pad.inc` の `pad_read`、ゲームのテンプレートが、実機では ON/BRK を読めていなかったのを直した。ON/BRK はキーの行列ではなく CPU の ON ピンにつながっているので、SSR のビット 3 で読むようにした（エミュレータは行列にも出すので、エミュレータでは読めていた）
- LCD にデータを続けて書くときは、1 バイトに 14 サイクル以上かける決まりをマニュアル、解析 4 章、スキルに書いた。それより速く書くと、実機の LCD がデータを取りこぼす（エミュレータでは崩れない）
- 解析 30 章「機械語を速くする」を追加した（LCD への転送、送る量の減らし方、内部 RAM、1 コマの時間、止めずに鳴らす音）。解析 9 章に、CPU 以外の IC のピンの図を足した。マニュアル 13 章に、キーを押している間 `INKEY$` が同じ文字を返し続けることと、その対処を足した
- AI 用のスキルが、別のリポジトリに移したゲームのサンプルを指さないようにした

## 0.1.0

Visual Studio Marketplace と Open VSX で出す最初の版です。発行者が変わったので、番号を 0.1.0 から振り直しました。

- 発行者を `litchi-gh` にした（ID は `litchi-gh.pc-e500-devtools`）。前の VSIX（`pokecom-tools.pc-e500-devtools`）を入れている場合は、アンインストールしてから入れる
- 設定画面に、エミュレータのダウンロードと、この拡張機能のマニュアルへのリンクを足した。「環境を確認」で、エミュレータが見つからないときや古いときに、ダウンロードのボタンを出す
- ドットエディタの文字入れのフォントを、SparkFun Electronics の 5 × 7 ドットのフォント（MIT）にした（`ThirdPartyNotices.txt`）

- INCLUDE ファイル: `iocs.inc`（IOCS の名前）、`hardware.inc`、`keycode.inc`、ゲーム用の `game.inc`・`screen.inc`・`sprite.inc`・`pad.inc`・`text.inc`・`random.inc`。IOCS の番号の候補と説明、スニペット
- キャラクタ `.spr` のエディタ（コマ、再生、透かし、縁取り、マスク）と、テンプレート「キャラクタを動かすゲーム」。「新しいドット絵を作成」「INCLUDE ファイルをコピー」
- 名前を「Pocket BASIC / ASM Linter」から「PC-E500 開発ツール」に変更（ID `pc-e500-devtools`、設定とコマンド `pcE500.*`）。古い名前の設定は引き継ぐ。方言の設定は廃止。アイコンを追加
- 「環境を確認」: アセンブラとエミュレータがそろっているかを調べ、足りないものをその場で直す。`e500asm` とエミュレータは、設定が空なら PATH から探す
- PC-E500 エミュレータとの連携を追加（Windows）。ASM をアセンブルしてエミュレータで実行・デバッグする（行・命令ブレークポイント、ステップイン／オーバー／アウト、呼び出し履歴、レジスタ・フラグの表示と書き換え、ラベル・内部 RAM の I/O、ウォッチ式、HEX メモリ、逆アセンブリ）
- LCD とキーボードのパネル（「PC-E500: エミュレータを開く」）。PC のキーボード・画面のキー・テキスト送信で入力、速度の切り替え、LCD の文字のコピー
- `*.e500test.json` のテストをテスト エクスプローラーで実行・デバッグ（ルーチンの呼び出しか BASIC の行、レジスタ・メモリ・画面の確認）
- BASIC（`.bas`）の実行とデバッグ。CE-140F から LOAD して RUN し、行ブレークポイント・行ごとのステップ・一時停止・変数（数値、文字列、配列）の表示・書き換えとウォッチ
- パネルの本体をエミュレータと同じ描き方にし（ケース・表示シンボル・キーの配置）、「本体」「画面だけ」の切り替えと「リアル表示」を追加
- エミュレータと同じデバッグ画面（メモリマップ、レジスタ、内部 RAM、1MB の HEX 表示と書き換え、BIN の書き込み・書き出し）
- ASM のラベル・`EQU`・`INCLUDE` の定義へ移動（Ctrl+クリック、F12）と入力候補（ニーモニック、疑似命令、レジスタ、ラベル、定数）
- BASIC の入力候補（命令、関数、変数、行番号、ラベル）と説明。ASM の命令・レジスタ・ラベルの説明（マウスを乗せたときと、候補の各行）
- `.lcd` と `.pixels` のファイルを開くドットエディタ（拡大と方眼、図形、選択と移動・反転・回転、文字、画像の読み込み、`DB` / `GPRINT` としてコピー）。`INCBIN` のファイル名を Ctrl+クリックで開く
- テストの `picture`（LCD が `.lcd` と同じか）と `keys`（押すキー）
- 「新しいプログラムを作成」（テンプレート 4 種）と「BIN を作成」（`LOAD M` 用、打ち込む行の表示、X: フォルダへのコピー）。エミュレータのフォルダを選択画面
- 日本語と英語に対応（VS Code の表示言語に合わせる）。設定・コマンドの説明は `package.nls.json` / `package.nls.ja.json`
- パネルに変数とウォッチの一覧（実行中も更新、ウォッチ式はワークスペースに保存）
- 止めているときの書き換え: レジスタ、フラグ、ラベルの中身、メモリ、内部 RAM（パネル、デバッグ画面、VS Code のデバッグ欄）
- README を短くし、説明を `docs/manual/` と `docs/design/` に移した
- デバッグを終えるときに停止ボタンを 2 回押さなくてよいようにした
- デバッグ画面のメモリマップの色が出ないことがあったのを直した。狭い画面では縦に並べる
- `ASSERT` と `LINE` の説明の書き方を直した
- コマンド `e500`（`bin/`）: アセンブル、逆アセンブル、文法チェック、テスト、実行（画面の文字と PNG）、BIN の作成、命令の検索、テンプレートを、VS Code を開かずに使える。Linux と macOS でも動く
- `e500 asm -f ce140f`（`LOAD M` のファイル）と、`e500 bin` の BASIC（`LOAD` 用のテキスト）
- アセンブラ: `PUSHS`、`POPS` に `A` `IL` `BA` `I` `X` `Y` `IMR` を書ける（`MV [--S],…`、`MV …,[S++]` になる）
- テスト: `"(名前)"` で内部 RAM を入れて調べる。`basic` の行を打つ時間は `maxCycles` に含めない
- AI アシスタント（Claude Code、Codex など）用のスキル `skills/pc-e500`。`e500 skill` か、コマンド「AI 用のスキルを置く」で自分のフォルダに置く。VS Code のターミナルでは設定なしで `e500` が使える
- `e500 asm`、`bin`、`dis` は、ソースや自分で作ったファイルを上書きしない（`dis` と `bin` の `--force` で置き換える）
- テストの書き間違い（知らない項目、0〜255 でないバイト、重なった名前）を間違いにする。これまでは何も調べずに通っていた
- BASIC の `F5`、`e500 run`: 長いプログラムを最後まで読み込む。途中の行を `LOAD` できなければ、その行を示して止まる。1 行目のブレークポイントで止まる。`X:` に書いたファイルを残す。文字列の小文字を小文字のまま打つ
- BASIC の診断を本体に合わせた（空白のない書き方、`"ラベル"`、省略形、`FOR` の組、`THEN` のジャンプ先など）。長すぎる行、番号だけの行、本体にない文字を見つける
- デバッグ: 実行中のリセットで止まったままになること、直接呼び出しの最初の命令のブレークポイント、2 回 INCLUDE したファイルのブレークポイント、`(BP)` の値、100 を超える配列の表示を直した
- BASIC のテスト: `*.e500test.json` の `program` に `.bas` を書ける（サブルーチンの呼び出し、変数、入力、終わり方）。ひな形「アプリ」「BASIC のアプリ」「BASIC のゲーム」
- ドットエディタ: 大きな絵の `GPRINT`、マスクのないキャラクタの反転、閉じている間に変わったファイルの上書きの確認を直した
- `DB` の文字列と文字定数は 20h〜7Fh の文字だけにした（`e500asm` も）。セグメントの違う近いジャンプの見落とし、シフトや `0` での除算を含む前方参照を直した
- 「制限モード」のフォルダでも編集の機能が使える。実行するファイルの設定は、信頼するまでフォルダから読まない
- 直接呼び出したルーチンの終わりを、ステップで越えたときも「終了」として止まる（これまでは何もないアドレスを進んでいた）
- デバッグを始めている最中に終了すると、`e500dbg` が残ることがあったのを直した
- テスト ファイルの文字列の中の `,]` `,}` を変えない。テストの除外の指定が効く
- `EQU` の式に未定義の名前があるとき、「循環」と報告しない。`ORG` と同じ行のラベルの値を `e500asm` とそろえた
- BASIC の診断で、注釈の中の `"` を数えない。行番号のすぐ後ろに命令があっても読む。`&H` だけの色分けを直した
- マスクのないキャラクタに「消灯」のドットが残ることがあったのを直した
- パネルの CSP の nonce を暗号用の乱数で作る。デバッグ画面に出す名前をエスケープする
- BASIC の命令の説明（`INIT`、`DSKF`、`MID$`、`KEY` など 16 件）と、IOCS・FCS の引数と結果の説明を、操作説明書、技術資料、ROM の動きに合わせて直し、足りないものを加えた
- BASIC の診断で `PRINT# 1,…` `INPUT# 1,…` を間違いにしない
- 設定 `pcE500.*`、デバッグサーバー `e500dbg`（`server/`）、サンプル `examples/hello.asm` と `hello.e500test.json`

- `[X-1+2]`、`(BP-1+2)`、`[(5)-1+2]` の変位を式どおりに計算する（これまでは `X-(1+2)` として誤ったアドレスを出力していた。`e500asm` と同じ修正）
- 「e500asm でアセンブル」で `.cmd` / `.bat` を使うとき、引数を引用符で囲む。ファイル名に `&` などがあると、その後ろがコマンドとして実行されていた
