# PC-E500 ハンドブック

PC-E500 シリーズの本体を使うための本です。電源の入れ方から、電卓、統計、行列、エンジニアソフト、BASIC のプログラム、カードや周辺機器まで、本体だけでできることを順に説明します。PC のツールの使い方は[マニュアル](../manual/README.md)、内部の仕組みは[解析](../analysis/README.md)にあります。

この本は、操作説明書や技術資料に書かれていることを、実際にエミュレータで動かして確かめながら、自分たちの言葉と例で説明し直したものです。画面の例は、とくに断りがなければ日本語の PC-E500（ROM 7.2、32 KB）のものです。英語版の PC-E500 で違うところは、それぞれの章に注記しました。PC-E500S などほかの機種との違いは[機種ガイド](../analysis/29_MODELS.md)にあります。

```mermaid
flowchart LR
  A["第 1 部<br>本体を知る"] --> B["第 2 部<br>計算する"]
  B --> C["第 3 部<br>BASIC"]
  C --> D["第 4 部<br>資料"]
```
