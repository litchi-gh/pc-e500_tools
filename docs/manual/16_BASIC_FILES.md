# 16. BASIC のファイルと文字

この章は、PC で書いた BASIC を実機へ渡すときと、実機の BASIC を PC で読むときの、ファイルの形と文字の話です。手順だけを知りたいときは[実機へ送る](14_TRANSFER.md#146-basic-のプログラム)にあります。

[目次へ戻る](README.md)

## 16.1 3 つの形

| 形 | 作り方 | PC のエディタで | 先頭のバイト |
|---|---|---|---|
| テキスト | PC で書く。実機では `SAVE "X:…",A` | 読める | 行番号の数字 |
| 中間コード | 実機の `SAVE "X:…"`（`,A` なし） | 読めない | `FFh` |
| 機械語 | `SAVE M`、「BIN を作成」、`e500 bin`、`e500asm -f ce140f` | 読めない | `FFh`（`FF 00 06 01 10`） |

PC で読み書きするのは**テキスト**です。中間コードのファイルは、実機で `LOAD` してから `SAVE "X:…",A` で保存し直すと、テキストになります。

## 16.2 テキストの決まり

| 項目 | 決まり |
|---|---|
| 行 | すべて行番号で始める。1 行 256 バイトまで |
| 改行 | CR+LF |
| 最後の行 | 改行を付ける |
| 末尾の `1Ah` | 付けない |
| 文字 | 1 文字 1 バイト。ASCII と半角カナ |

```text
10 PRINT "HELLO"
20 END
```

これを実機に渡すバイト列にすると、次のようになります。

```text
0000  31 30 20 50 52 49 4e 54 20 22 48 45 4c 4c 4f 22  10 PRINT "HELLO"
0010  0d 0a 32 30 20 45 4e 44 0d 0a                    ..20 END..
```

## 16.3 文字

| 本体のバイト | 文字 | UTF-8 のファイル | Shift JIS のファイル |
|---|---|---|---|
| `20h`〜`7Eh` | ASCII | 同じ 1 バイト | 同じ 1 バイト |
| `5Ch` | `¥`（英語の機種は `\`） | `¥` は 2 バイト（`C2 A5`）、`\` は 1 バイト | 同じ 1 バイト |
| `A1h`〜`DFh` | 半角カナ | 3 バイト（`ｱ` は `EF BD B1`） | 同じ 1 バイト |
| その他 | 記号、ギリシャ文字など | 対応なし | 対応なし |

- 英数字と記号だけなら、UTF-8 のままで渡せます。
- **半角カナを使うときは、UTF-8 のままでは化けます。** 次の 16.4 のどちらかで、1 バイトの文字にします。
- 全角の文字は、本体にはありません。
- PC にない記号は、`CHR$` で書きます。番号は[フォント](../analysis/13_FONT.md)にあります。

## 16.4 PC から実機へ

### e500 bin

```text
e500 bin prog.bas -o OUT.BAS
```

| 部分 | 何をするか |
|---|---|
| `bin prog.bas` | BASIC のソース（UTF-8）を、実機の `LOAD` で読めるテキストにする |
| `-o OUT.BAS` | 作るファイル。X: では 8 文字までの大文字の名前にする |

改行を CR+LF にし、半角カナと `¥` を 1 バイトにし、空の行と行番号のない行を除きます。本体にない文字は除いて、どの文字かを表示します。

```text
OUT.BAS: 26 バイト
  LOAD "X:OUT.BAS"
  RUN
```

`-o` を付けないと、ソースの隣に大文字の名前で作ります。Windows と macOS では `prog.bas` と `PROG.BAS` が同じファイルになるので、その場合は止まって知らせます。`e500` の準備は [22 章](22_COMMAND_LINE_AI.md)にあります。

### VS Code で Shift JIS にする

ツールを使わずに、VS Code だけでもできます。半角カナは、Shift JIS では本体と同じバイトです。

1. 画面右下の「UTF-8」→「エンコード付きで保存」→「Japanese (Shift JIS)」を選ぶ。
2. 画面右下の「LF」→「CRLF」を選び、保存する。
3. 最後の行の後に、改行が 1 つあることを確かめる。

できたファイルを、そのまま X: に置きます。`¥` は `\` と打ちます。

## 16.5 実機から PC へ

```basic
SAVE "X:PROG.BAS",A
```

`,A` を付けると、テキストで保存されます。英数字だけなら、VS Code でそのまま読めます。カナが化けるときは、画面右下の「UTF-8」→「エンコード付きで再度開く」→「Japanese (Shift JIS)」を選びます。

## 16.6 エミュレータで動かすとき

VS Code の `F5` と `e500 run` は、文字と改行を自分で変えてから読み込みます。`.bas` は UTF-8 のままでかまいません。

## 16.7 困ったとき

| 症状 | 原因と対処 |
|---|---|
| `LOAD` がエラーになる | 行番号のない行、256 バイトを超える行がある。`e500 lint` で調べる |
| 最後の行がない、最後にエラーが出る | 最後の行に改行がない、または末尾に `1Ah` がある。`e500 bin` で作り直す |
| カナが別の文字になる | UTF-8 のまま渡した。16.4 の方法で作り直す |
| PC で開くと文字が壊れている | 中間コードで保存した。実機で `SAVE "X:…",A` をやり直す |
| `出力がソースと同じファイルになります` | `-o` で別の名前を指定する |
