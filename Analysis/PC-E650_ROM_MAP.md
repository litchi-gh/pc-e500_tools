# ROMマップと主要入口

## 対象と物理配置

ファイル長は `60000h` (384 KiB)。ファイルを連続したCPUアドレスへ置く形式ではない。

| file offset | CPUアドレス | 長さ | 内容 |
|---|---|---|---|
| 00000h-1FFFFh | 20000h-3FFFFh | 128 KiB | PC-E650拡張ROM |
| 20000h-5FFFFh | C0000h-FFFFFh | 256 KiB | 本体ROM |


`20000h-2FFFFh` と `34000h-3FFFFh` は全バイト `FFh`。実データのある拡張ROMは `30000h-33A18h`。本体ROM先頭 `C0000h` から約128 KiBはG:のROMディスクとその予約領域を含み、実行コードの主領域は概ね `E0000h` 以降である。

## 固定入口

| アドレス | 内容 | 意味 |
|---|---|---|
| FFFD8h | JPF F96C8h | 公開補助入口（既存利用例あり） |
| FFFDCh | JPF EF02Fh | 公開補助入口 |
| FFFE4h | JPF E06BFh | FCS（File Control System） |
| FFFE8h | JPF E0000h | IOCS |
| FFFFAh | F209Bh | 割込みベクタ |
| FFFFDh | F10BEh | リセットベクタ |


## 確定した主要領域

| 範囲/先頭 | 内容 | 主な根拠 |
|---|---|---|
| 30000h-305FFh | 6x8文字ドット256字（各6バイト） | F2445hの文字コード分岐、F2528hが設定するRAMポインタ、表示実測 |
| 30798h | 代替/制御文字用ドット列の先頭候補 | BFC84hへ設定されF25E7hから参照。用途の細分は未確定 |
| C0000h-C0017h | ROM内メモリブロック管理領域 | E4BE8hがC0018hを固定参照 |
| C0018h-DFFFFh | G: RAMFILEブロック（ROMに焼かれた読出し用イメージ） | IOCS device 5、drive 2。BPB/FAT12/ディレクトリ整合と実行時COPYで確認 |
| DF800h-DF8B8h | IOCSヘッダ連結リスト | RAM BFCA2hがDF820hを指す。10ヘッダを末尾FFFFFFhまで追跡 |
| DFD00h-DFFFFh | 第2の6x8ドット群 | 連続ドット配列。通常文字表示で使う30000h表とは別。用途未確定 |
| E0000h | IOCSメインルーチン | FFFE8hからJPF、技術資料の公開ABIと一致 |
| E06BFh | FCSディスパッチ | FFFE4hからJPF、00h-11hの18項目表を参照 |
| E493Ah-E4C69h | RAMディスク/メモリブロック制御の主要部 | device 5入口E493Ah、G:でC0018hへ分岐 |
| EF02Fh | Function driver入口 | IOCS device 9およびFFFDChから到達 |
| F10BEh | リセット処理 | FFFFDhリセットベクタ |
| F209Bh | 割込み処理 | FFFFAh割込みベクタ |
| F2445h-F2551h | 文字ドット選択とポインタ初期化 | 文字コード帯別分岐とBFC84h-BFC95hへの設定 |
| F4E29h-F5028h | トークン逆引き/補助表 | F4939hが参照、256個の16-bit項目 |
| F5029h-F5328h | BASICトークン処理レコード表 | F5930h/F5963hが token*3 で参照 |
| F5334h-F5762h | BASICキーワード辞書168項目 | [長さ][ASCII名][token]。技術資料の中間コード表と一致 |
| F5763h以降 | BASIC中間コードディスパッチ主要部 | トークン分類、F592Ah/F5963h経由の処理入口選択 |
| FFFD8h-FFFFFh | 公開入口とベクタ、ROM 8.5トレーラ | JPF群、割込み/リセットベクタ、末尾08 05 |


## コード到達解析

公開ベクタ、IOCS/FCS全表、BASIC全トークン入口、文字初期化をseedに再帰走査し、39,310個の命令開始、94,090バイトを重複なしで到達可能コードとして得た。未解決デコード停止は 0 件。これは「ROM中の全コード」と同義ではなく、間接ジャンプ先や未発見入口は含まれない。

## RAM上の重要ポインタ（ROM 8.5実行時）

| RAM | 値/用途 |
|---|---|
| BFCA2h | DF820h: IOCSヘッダ先頭 |
| BFC84h-BFC95h | 文字コード帯別の6個の20-bitドット表ポインタ |
| BFC90h | 300C0h: ASCII 20hのドット |
| BFC93h | 303C0h: 半角カナ A0h側のドット |


## 確度

「確定」はROMの固定参照または表構造を複数の方法で確認したもの。「強い根拠あり」はコード参照とデータ形状が一致するもの。「未確定」は役割名の細分が資料または実機追跡で確定していないもの。全域ASMに見える命令境界はこの区分に使っていない。
