# 回路とサービス情報

本体の部品、ピンの割り当て、消費電流、サービス用の検査ソフトをまとめた資料です。主な情報源はサービスマニュアルです。OCR の文字で読んだので、数字は原本で確かめてください。

## 情報源

| 表記 | 情報源 |
|---|---|
| **PC-E500** | PC-E500 Service Manual |
| **PC-E500S** | PC-E500S Service Manual |
| **CPU 資料** | ESR-L CPU Technical Manual |

## 1. 仕様

| 項目 | 値 |
|---|---|
| 表示 | 40 桁 × 4 行（5×7 ドット）、240×32 ドット |
| 計算 | 単精度 10 桁 + 指数 2 桁、倍精度 20 桁 + 指数 2 桁 |
| CPU | CMOS 8 ビット、SC62015B01 |
| システム領域 | 約 3.8 KB |
| 固定変数 | 312 バイト |
| プログラムとデータ | 28600 バイト |
| スタック | 合計 145 バイト。サブルーチン 1 段 4 バイト、FOR-NEXT 1 段 21 バイト |
| シリアル | 300〜9600 bps、C-MOS レベル（4〜6 V） |
| 動作温度 | 0〜40 °C |
| 電源 | DC 6 V（単 4 形 4 本） |
| 電池の持ち | 約 70 時間（20 °C、1 時間に計算 10 分、表示 50 分） |
| 消費電力 | 0.07 W |
| 大きさ | 200×100×14 mm |
| 重さ | 250 g（電池込み） |

サービスマニュアルの仕様とメモリマップの ROM の記載は 128 KB（`E0000h`〜`FFFFFh`）ですが、同じマニュアルの回路図は 256 KB で、手元の ROM イメージはどの版も 256 KB か 384 KB です。

## 2. 主な部品

CPU、ROM、RAM、LCD コントローラは [IC_CHIPS.md](IC_CHIPS.md) にあります。ほかの IC は次のとおりです。

| 役割 | PC-E500 | PC-E500S |
|---|---|---|
| 電池検出 | MN1280Q（IC7） | RH5VA39A |
| ロジック | TC4S81F（IC8）、TC7S04F（IC9）、TC4S66F（IC10） | TC7S02F（IC9）、TC4S66F（IC10）、TC3W01F（IC12）、TC7S08F（IC13）、TC4S11F（IC14）、TC4S81F |

PC-E500S のシステム構成図には CE-135T が載っていて、CE-515P はありません。

## 3. CPU のピン

PC-E500S のサービスマニュアルの表です（OCR の列がずれている部分は順序で対応づけました）。

### 3.1 クロック、電源、制御

| ピン | 信号 | 内容 |
|---|---|---|
| 1、2 | X1、X2 | セラミック発振 |
| 3、4 | X3、X4 | CR 発振 |
| 5 | VDD | 表示電源の制御 |
| 6 | VCC | 電源 + |
| 7 | RESET | リセット（High で動作） |
| 8 | GND | 電源 - |
| 9 | TEST | テスト入力 |
| 10 | CI | カセット信号の入力 |
| 11 | CO | カセット信号の出力 |
| 12 | ON | ON キー（通常 Low） |
| 13 | WR | 書込みクロック（通常 High） |
| 59 | IRQ | 電池検出 |

### 3.2 チップセレクト

| ピン | 信号 | 範囲 | 内容 |
|---|---|---|---|
| 62 | CE6 | `10000h`〜`1FFFFh` | ROM カード（Active High）。[CARD_SLOT.md](CARD_SLOT.md) |
| 63 | CE5 | `00000h`〜`03FFFh`、`08000h`〜`0BFFFh` | 表示チップ（Active High）。[LCD.md](LCD.md) §2 |
| 66 | CE2 | `C0000h`〜`FFFFFh` | 内蔵 ROM |
| 67 | CE1 | `40000h`〜`7FFFFh` | RAM カード。[CARD_SLOT.md](CARD_SLOT.md) |
| 68 | CE0 | `80000h`〜`BFFFFh` | 内蔵 RAM |

PC-E500 では CE3、CE4、CE7 は未使用です。`20000h`〜`3FFFFh`（CE3）は PC-E650 と PC-U6000 の拡張 ROM が使います（[ROM_VERSIONS_MAP.md](ROM_VERSIONS_MAP.md)）。この 2 機種と PC-E500S の基板では、CE2 と CE3 が同じ ROM につながります（[IC_CHIPS.md](IC_CHIPS.md) §3.3）。

| ピン | ポート | 内部 RAM | 内容 |
|---|---|---|---|
| 85〜88 | E15〜E12 | `F6h` 上位 | CE-140F のデータ入力 |

| 93 | E7 | `F5h` | 11 ピン ACK |
| 94 | E6 | `F3h` | 11 ピン BUSY |

| KO | `F1h` のビット | 内容 |
|---|---|---|

## 4. 消費電流

11 ピンの 2 番に DC 5 V、3 番に 0 V を与えて測る条件です。

| 状態 | PC-E500 | PC-E500S |
|---|---|---|
| 動作（BASIC で `>` を表示） | 3.24 mA 以下 | 3.29 mA 以下 |
| 電源オフ | 64 µA 以下 | 22.8 µA 以下 |

チップごとの電流は [IC_CHIPS.md](IC_CHIPS.md) §6 にあります。

## 5. サービス用の検査ソフト

サービスマニュアルに、RAM に入れて実行する検査プログラムの説明があります（ROM の診断メニューとは別です。ROM のものは [ROM_VERSIONS_SYSTEM.md](ROM_VERSIONS_SYSTEM.md) §2.4）。

| メニュー | 検査 | 内容 |
|---|---|---|
| 1 DISP | 液晶 | 交互の表示、全シンボルの点灯 |
| 2 ROM | マスク ROM | 約 6 秒。`EX Ver. 1 (LH5320XH)` と結果を表示（表示の一覧は [IC_CHIPS.md](IC_CHIPS.md) §3.2） |
| 3 RAM | 内蔵 RAM | 読み書き |
| 4 11 PIN | 11 ピン | 治具 UKOGC3020CSZZ が必要 |
| 5 15 PIN | 15 ピン | 同じ治具 |
| 6 CARD | RAM カード | 容量を選ぶ。内容は消える |

カードの検査のメニューには 2 KB と 4 KB があり、範囲は次のとおりです。

| 容量 | 範囲 |
|---|---|
| 2 KB | `40000h`〜 |
| 4 KB | `40000h`〜 |
| 8 KB | `40000h`〜`41FFFh` |
| 16 KB | `40000h`〜`43FFFh` |
| 32 KB | `40000h`〜`47FFFh` |
| 64 KB | `40000h`〜`4FFFFh` |

エラーは番号、正常値、実際の値の形で表示します（例：`1 13 0`）。

## 6. 改造の報告

メーカーの資料ではなく、個人や販売店の報告です。**試していません。**

| 内容 | 報告 |
|---|---|
| 内蔵 RAM 128 KB | HM62256A を 128 KB の SRAM（M5M51008DFP）に交換。32 ピンを VCC へ、31 ピンを A15 へ、2 ピンを A16 へ。A15 と A16 は CPU の近くのパッドから |
| 内蔵 RAM 256 KB | 3 個の RAM を追加し、2 個を重ねて付ける。チップセレクトの配線を追加 |
| クロック | セラロックを 4.8 MHz に、180 kΩ を 68 kΩ に変える報告。4.00 MHz、4.55 MHz の部品も販売されている |
| 256 KB RAM カードの自作 | HC138 と 128 KB SRAM 2 個、CR1216、書込み禁止スイッチ、基板 41.9×54.1×0.8 mm。KiCad のデータが公開されている |

出典は [EXTERNAL_RESOURCES.md](EXTERNAL_RESOURCES.md) にあります。
