# キャラクタドット格納先

通常表示で使う6x8ドットは `30000h-305FFh`。256文字 x 6 bytesで、1文字の各byteが縦8ドットの1列、bit 0が上側。文字コード `c` の先頭は `30000h + c * 6`。

リセット中の `F2528h` が6個のポインタを `BFC84h-BFC95h` へ設定し、`F2445h` が文字コード帯ごとに選ぶ。実行時に得た値は次の通り。

| 文字コード帯 | RAM pointer | 値 | 実効base |
|---|---|---|---|
| 制御/代替 | BFC84h | 30798h | 用途詳細未確定 |
| 00h-1Fh | BFC87h | 30000h | 30000h |
| 80h-9Fh | BFC8Ah | 30300h | 30000h |
| E0h-FFh | BFC8Dh | 30540h | 30000h |
| 20h-7Fh | BFC90h | 300C0h | 30000h |
| A0h-DFh | BFC93h | 303C0h | 30000h |


`DFD00h-DFFFFh` にも6バイト単位の別ドット群がある。通常文字ルーチンのポインタ先ではないため、本資料では第2フォント候補として扱い、用途は未確定とする。
