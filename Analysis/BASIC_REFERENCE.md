# BASIC命令・関数リファレンス

PC-E500 ROM 8.5 の BASIC キーワード辞書と処理表から復元した 168 キーワードの索引に、各命令の使い方（機能・書式・引数）を加えたものである。使い方は PC-E500 操作説明書の BASIC COMMAND DICTIONARY を日本語で要約したもので、細かなエラー条件や画面上の挙動は原本（PC-E500 操作説明書）または該当する ROM コードで確認すること。

## 使い方

1. 命令の意味や書き方を知りたいときは「命令の使い方（アルファベット順）」「数値関数」「ROM 8.5 拡張」の各節を引く。
2. 中間コードを読む・作るときは「全キーワード」表で `token` と `分類` を確認する。BASIC の保存形式や逆アセンブルでは、通常 `FEh token` がそのキーワードを表す。例: `PRINT` は `FE 60`。
3. 実装・解析時に処理を追う場合だけ、`処理入口` と `表アドレス` を用いる。ユーザープログラムから ROM 入口を直接呼ぶための表ではない。

```basic
10 A=1
20 PRINT A
30 END
```

この例の `PRINT` は辞書上 token `60h` で、中間コード中では通常 `FE 60` として現れる。ただし文字列リテラル中の文字列（例: `PRINT "PRINT"`）はキーワードとしてトークン化されない。

### 表の読み方

| 列 | 内容 |
|---|---|
| キーワード | ROM 辞書に入っている ASCII 名。大文字小文字の表記は辞書どおり。 |
| token | 1 バイトのキーワード番号。中間コードでは通常この前に `FEh` が付く。 |
| 名前アドレス | 辞書中のキーワードレコードの位置。 |
| 表アドレス | `F5029h + token × 3` で得られる 3 バイト処理レコードの位置。 |
| raw | 処理レコードの未加工 3 バイト値。上位ビットは種別フラグを含む。 |
| 分類 | `文`、`関数`、`内部/複合`、`予約` の解析結果。 |
| 処理入口 | ROM 上の実行入口。`-` は公開の実行入口を持たない/未確定の項目。 |

## トークン化と処理入口

- キーワード辞書は `F5334h-F5762h` にあり、レコード形式は `[名前長][ASCII名][1-byte token]`。この ROM では 168 項目を確認した。
- 中間コードは通常 `FEh token`。文字列リテラル中はトークン化しない。中間コードを復元する際は、単に `FEh` を置換せず文字列境界も扱う。
- 処理レコード表は `F5029h + token * 3`。20-bit アドレスに上位フラグを重ねた 3 バイト値である。
- `文` は raw pointer の bit 23 が立つ項目で、下位 20 bit が入口である。
- `関数` は bit 22 が立つ項目で、下位 20 bit は 3 バイトの前置レコードを指す。実行入口はそのアドレス `+3`。
- `SAVE M` / `LOAD M` は独立キーワードではない。`SAVE` (`23h`) / `LOAD` (`18h`) の引数修飾子として解析される。

`OPEN$` と `RESERVED` は辞書にあるが処理レコード値が 0 である。予約語または構文上の特殊項目として扱い、通常の関数と同じ入口があるとはみなさない。構造化 BASIC の `IF`、`REPEAT`、`CASE` などは拡張 ROM `30000h` 台へ処理が渡る。

## 命令詳細: 制御構文

### GOSUB / RETURN

**機能**: `GOSUB` は指定したサブルーチンへ制御を移し、`RETURN` は呼出し元の `GOSUB` の直後（同一行で `:` に続く文があればその文）へ戻る。

**書式**:

```basic
GOSUB 行番号
GOSUB *ラベル
RETURN
```

**引数**:

| 引数 | 指定内容 |
|---|---|
| 行番号 | サブルーチン先頭の既存行番号 |
| `*ラベル` | サブルーチン先頭に置いたラベル |

**例**:

```basic
100 GOSUB 500: PRINT A
110 END
500 A=A+1
620 RETURN
```

この例では `500` 行から `620` 行までを実行した後、`100` 行の `PRINT A` を実行する。サブルーチンの末尾には `RETURN` を置く。操作説明書ではネストは最大 36 段までとされる。

**関連**: `GOTO`、`ON ... GOSUB`。

### GOTO

**書式**:

```basic
GOTO 行番号
GOTO *ラベル
```

指定先へ一方向に移る。サブルーチン呼出しではないため、呼出し元に戻る必要がある処理には `GOSUB` / `RETURN` を使う。

### ON ... GOSUB / ON ... GOTO

**書式**:

```basic
ON 式 GOSUB 行番号1, 行番号2, ...
ON 式 GOTO  行番号1, 行番号2, ...
```

式の値で移動先を選ぶ。`ON ... GOSUB` の各候補は `RETURN` で戻るサブルーチンにする。ラベルも行番号の代わりに指定できる。

### IF ... THEN ... ELSE

**書式**:

```basic
IF 条件 THEN 文
IF 条件 THEN 行番号
IF 条件 THEN *ラベル ELSE 文
```

条件が真なら `THEN` 側、偽なら `ELSE` 側を実行する。行番号またはラベルを指定した場合はその位置へ移る。比較には `=`, `<>`, `<`, `>`, `<=`, `>=` を使用する。

### FOR ... NEXT

**書式**:

```basic
FOR 変数 = 開始値 TO 終了値 [STEP 増分]
  ...
NEXT [変数]
```

開始値から終了値まで繰り返す。`STEP` を省略したときの増分は `1`。ループの途中で `CLEAR`、`DIM`、`ERASE` を実行しない。また、通常の流れで `FOR ... NEXT` の外へ飛び出さない。

## 命令の使い方（アルファベット順）

各項目は **機能**（何をする命令か）、**書式**、**引数**、必要に応じて **備考** で構成する。角括弧 `[]` は省略可能、`{A | B}` はどちらか一方、`...` は同種の指定の繰り返しを表す。書式中の日本語（`式`、`行番号` など）は、実際には数値や変数名に置き換える。

出典は PC-E500 操作説明書（BASIC COMMAND DICTIONARY および数値関数の章）である。`CALL` / `PEEK` / `POKE` は `PC-E650_ASSEMBLER_MANUAL.md` §7 の検証結果、構造化 BASIC（`WHILE` など）は ROM 8.5 拡張の項に分けて記す。

共通の引数表記:

| 表記 | 意味 |
|---|---|
| `式` | 数値として評価される式。定数、変数、演算式、数値関数を書ける。 |
| `文字列` | 文字列定数（`"ABC"`）、文字列変数、文字列式。 |
| `行番号` | プログラム内に存在する行番号。 |
| `*ラベル` | 行の先頭に置いた `*` 付きラベル。行番号の代わりに指定できる。 |
| `d:` | デバイス名。`X:` ポケットディスク、`E:` / `F:` RAM ディスク、`CAS:` テープ、`COM:` シリアル。 |
| `"d:ファイル名"` | デバイス名付きファイル名。拡張子省略時は `.BAS`。 |

### AER

**機能**: AER モードで登録した代数式（番号付き）を BASIC から実行し、その値を返す。

**書式**:

```basic
AER 番号 [(式, 式, ...)]
```

**引数**:

- **番号**: AER モードで式に付けた番号。
- **式**: 登録した式の変数に渡す値。登録時の変数順に対応する。

**備考**: 使えるのは単精度数値変数だけで、文字列変数・倍精度変数は使えない。

### ARUN

**機能**: 電源投入時（RUN モード）に、変数と配列を初期化してからプログラムを自動実行するよう設定する。

**書式**:

```basic
ARUN [{行番号 | *ラベル}]
```

**引数**:

- **行番号 / `*ラベル`**: 開始位置。省略時は先頭行。

**備考**: `AUTOGOTO` と似ているが、固定変数以外の変数・配列をクリアしてから実行する。オートパワーオフ後の再投入では自動実行されない。

### ASC

**機能**: 文字列の先頭 1 文字の文字コードを返す。

**書式**:

```basic
ASC 文字列
```

**引数**:

- **文字列**: 文字列定数または文字列変数。

### AUTO

**機能**: PRO モードで行番号を自動的に挿入する。

**書式**:

```basic
AUTO [開始行番号 [,増分]]
```

**引数**:

- **開始行番号**: 最初に表示する行番号。省略時は 10。
- **増分**: 行番号の間隔。省略時は 10。

**備考**: `SHIFT`+`CA`、電源の切入、PRO/RUN 以外のモードへ移ると解除される。行番号だけが表示された状態で `C・CE` または `BREAK` を押しても解除される。

### AUTOGOTO

**機能**: 電源投入時（RUN モード）に、指定位置からプログラムを自動実行するよう設定する。変数はクリアしない。

**書式**:

```basic
AUTOGOTO {行番号 | *ラベル}
```

**引数**:

- **行番号 / `*ラベル`**: 開始位置。

### BASIC

**機能**: TEXT モードを解除して BASIC モードに戻す。テキストとして保持している内容を中間コードのプログラムに変換する。

**書式**:

```basic
BASIC
```

**引数**: なし。

**備考**: 変換中は画面右下に `*` が出る。約 600 バイトの作業領域を使い、変換後の 1 行が長すぎるとエラー。パスワードが設定されているとエラー。

### BEEP

**機能**: 内蔵スピーカーから指定した音程・長さのビープ音を指定回数鳴らす。

**書式**:

```basic
BEEP 回数 [,[音程][,長さ]]
```

**引数**:

- **回数**: 鳴らす回数。正の数値で最大 65535。
- **音程**: 0--255。値が大きいほど低音。省略時は 12。周波数(Hz) = 256000 / (90 + 4 × 音程)。0 で約 2844 Hz、255 で約 231 Hz。
- **長さ**: 0--65535。省略時は 583。同じ値でも低音ほど実時間は長くなる。

**備考**: 音程・長さの両方を省略すると約 4 kHz のビープになる。`BREAK` で停止できる。

```basic
10 FOR I=1 TO 3
20 FOR J=5 TO 25 STEP 5
30 BEEP I,J,150
40 NEXT J
50 NEXT I
```

### CALL

**機能**: 指定番地の機械語ルーチンを呼び出す。

**書式**:

```basic
CALL 番地
```

**引数**:

- **番地**: 20 bit の実行開始番地。`&HBEC00` のような 16 進、または 10 進で書く。

**備考**: ROM 8.5 の `CALL` に引数はなく、`CALL 番地, 値` の形は受け付けない。データの受渡しは `POKE` / `PEEK` で行う。機械語側は `RETF` で戻り、C=1 で戻ると A がエラー番号として扱われる。詳細は `PC-E650_ASSEMBLER_MANUAL.md` §7.3。

### CHAIN

**機能**: 実行中のプログラムから、指定デバイス上の別プログラムを読み込んで実行を引き継ぐ。変数は保持される。

**書式**:

```basic
CHAIN
CHAIN "d:ファイル名" [,{行番号 | *ラベル}]
```

**引数**:

- **`"d:ファイル名"`**: 読み込むプログラム。`d:` は `X:`、`E:`、`F:`、`CAS:`、`COM:`。
- **行番号 / `*ラベル`**: 開始位置。省略時は最小行番号。

**備考**: 引数なしの形はテープ専用で、最初に見つかったプログラムを読み込む。`CSAVE` で保存したプログラムは `CHAIN` できない（`SAVE` を使う）。`CAS:` / `COM:` を使う場合はそのデバイスのファイルを閉じておく。

### CHR$

**機能**: 文字コードに対応する 1 文字の文字列を返す。

**書式**:

```basic
CHR$ 式
```

**引数**:

- **式**: 文字コード 0--255。`&H5A` のような 16 進も可。255 を超えるとエラー。

### CIRCLE

**機能**: プリンタ（CE-515P）で円・弧・扇形・楕円を描く。GRAPH モードで使う。

**書式**:

```basic
CIRCLE (式1, 式2), 式3 [,式4][,式5][,式6][,式7][,式8][,式9]
```

**引数**:

- **式1, 式2**: 中心座標（-999--999）。
- **式3**: 半径。
- **式4**: 線の色（0--3）。省略時は前回の値。
- **式5, 式6**: 開始角と終了角（-2047--2047）。省略時は 0 と 360。
- **式7**: 縦横比 ry/rx。1 で円、それ以外で楕円。省略時は 1。
- **式8**: ピッチ角（1--2047）。省略時は 1。
- **式9**: 0 で弧、1 で扇形。

### CLEAR

**機能**: プログラムで使った変数を消去し、固定変数を 0 または空文字列に戻す。

**書式**:

```basic
CLEAR [変数1, 変数2, ..., 変数n]
```

**引数**:

- **変数**: 指定した場合、その変数だけを対象にする。

**備考**: `FOR ... NEXT` の中では使わない。特定の配列だけを消すには `ERASE`。

### CLOAD

**機能**: テープに保存したプログラムを読み込む。

**書式**:

```basic
CLOAD
CLOAD "ファイル名"
```

**引数**:

- **ファイル名**: 探すプログラム名。省略時は最初に見つかったプログラムを読み込む。

**備考**: `CSAVE` で保存したプログラムだけが対象。指定名が見つからないと探し続けるので `BREAK` で止める。

### CLOAD?

**機能**: テープ上のプログラムとメモリ上のプログラムを比較する。

**書式**:

```basic
CLOAD?
CLOAD? "ファイル名"
```

**引数**:

- **ファイル名**: 比較するプログラム名。省略時は最初に見つかったプログラム。

**備考**: 一致しないとエラーになる。

### CLOSE

**機能**: `OPEN` で開いたファイルを閉じる。

**書式**:

```basic
CLOSE [#ファイル番号, #ファイル番号, ...]
```

**引数**:

- **#ファイル番号**: 閉じるファイル。省略時は開いている全ファイル。

**備考**: `END` / `RUN` の実行、電源断、PRO/RUN 以外のモードへの移動、`LOAD` / `CLOAD` / `MERGE` の実行でも全ファイルが閉じられる。

### CLS

**機能**: 画面を消去する。

**書式**:

```basic
CLS
```

**引数**: なし。

### COLOR

**機能**: プリンタ（CE-515P）で描画・印字する色を指定する。

**書式**:

```basic
COLOR 式
```

**引数**:

- **式**: 0 黒、1 青、2 緑、3 赤。

### CONSOLE

**機能**: `LPRINT` / `LLIST` などでプリンタやシリアルへ送るときの 1 行あたりの桁数を設定する。

**書式**:

```basic
CONSOLE [式]
```

**引数**:

- **式**: 1--160。1--7 は 7 桁、160 超は 160 桁になる。0 以下はエラー。省略時は現在値を保持。

**備考**: 電池交換やリセット時は 39 桁。23 桁以下だと `LLIST` はエラー。

### CONT

**機能**: `STOP` や `BREAK` キーで一時停止したプログラムの実行を再開する。

**書式**:

```basic
CONT
```

**引数**: なし。

**備考**: `WAIT` で無限待ちになった `PRINT` / `GPRINT` の続行にも使える。

### COPY

**機能**: ファイルを別のデバイスまたは別名にコピーする。

**書式**:

```basic
COPY "d1:ファイル名1" TO "[d2:]ファイル名2" [,A]
```

**引数**:

- **`d1:`**: コピー元。`X:`、`E:`、`F:`、`CAS:`、`COM:`。
- **`d2:`**: コピー先。上記に加え `Y:`（同じドライブで別ディスク）が使える。
- **`,A`**: ASCII 形式でコピー。

**備考**: ワイルドカード `*` `?` が使える（`CAS:` / `COM:` を除く）。コピー先が書込み禁止（`SET`）だとエラー。

### CROTATE

**機能**: プリンタ（CE-515P）の文字の向きと印字方向を指定する。GRAPH モードで使う。

**書式**:

```basic
CROTATE 式
```

**引数**:

- **式**: 0--3。0 が通常の向きで、90 度ずつ回転する。

**備考**: `LTEXT` を実行すると 0 に戻る。

### CSAVE

**機能**: メモリ上のプログラムをテープに保存する。

**書式**:

```basic
CSAVE
CSAVE "ファイル名"
CSAVE "ファイル名", "パスワード"
CSAVE , "パスワード"
```

**引数**:

- **ファイル名**: テープ上の名前。ワイルドカードや拡張子のピリオドは使えない。
- **パスワード**: 付けると、読み込みは誰でもできるが `LIST` や変更にはパスワードが要る。

**備考**: プログラムが書込み禁止のときは無視される。

### CSIZE

**機能**: プリンタ（CE-515P）の文字サイズを指定する。

**書式**:

```basic
CSIZE 式
```

**引数**:

- **式**: 1 が最小（0.8 mm × 1.2 mm）。2, 3, 4, ... はその倍数。プリンタの電源投入時は 2。

### DATA

**機能**: `READ` で読み出す定数を並べておく。

**書式**:

```basic
DATA 値, 値, ...
```

**引数**:

- **値**: 数値または文字列。文字列に `,` や先頭空白を含む場合は `"` で囲む。

**備考**: 実行中に `DATA` 行に到達しても何もしないので、どこに置いてもよい。`RESTORE` で読み直せる。

### DEFDBL

**機能**: 1 文字名の変数を倍精度と宣言する。引数なしの形は以後の計算をすべて倍精度で行う（画面に DBL 表示）。

**書式**:

```basic
DEFDBL 文字範囲
DEFDBL
```

**引数**:

- **文字範囲**: `A`、`A-C`、`A,C,E-G` のような変数名の先頭文字の並び。

**備考**: 配列を倍精度にするには `DIM` より先に `DEFDBL` を実行する。`DEFSNG`、電源断、`RUN` / `NEW`、プログラムの読込み（`CHAIN` を除く）で解除される。`#` 付きの変数名が優先される。

### DEFSNG

**機能**: 1 文字名の変数を単精度と宣言する。引数なしの形は `DEFDBL` の倍精度モードを解除する。

**書式**:

```basic
DEFSNG 文字範囲
DEFSNG
```

**引数**:

- **文字範囲**: `DEFDBL` と同じ。

### DEGREE

**機能**: 三角関数の角度単位を度（10 進）にする。`GRAD` / `RADIAN` を実行するまで有効。

**書式**:

```basic
DEGREE
```

**引数**: なし。

### DELETE

**機能**: 指定した範囲のプログラム行を削除する。

**書式**:

```basic
DELETE 行番号
DELETE 行番号,
DELETE 行番号1,行番号2
DELETE ,行番号
```

**引数**:

- **行番号**: それぞれ、その行だけ / その行から最後まで / 行番号1 から行番号2 まで / 先頭からその行まで。

**備考**: RUN モードでの使用、存在しない行、開始 > 終了はエラー。パスワード設定中は実行されない。全削除は `NEW`。

### DIM

**機能**: 数値配列・文字列配列の領域を確保する。

**書式**:

```basic
DIM 配列名1(サイズ1[, サイズ2, ...]) [, 配列名2(サイズ1[, ...])] ...
```

**引数**:

- **配列名**: 変数名。`$` を付けると文字列配列、`#` を付けると倍精度配列。
- **サイズ**: 添字の最大値（0--65534）。要素数は サイズ+1。文字列配列は `A$(10)*20` のように要素長を指定できる。

**備考**: `FOR ... NEXT` の中では使わない。文字列配列は合計 64 KB まで。

### DSKF

**機能**: ポケットディスクまたは RAM ディスクの空き容量（バイト）を返す。

**書式**:

```basic
DSKF (d:)
DSKF (n)
```

**引数**:

- **`d:`**: `X:`、`E:`、`F:`。
- **n**: 1 ポケットディスク、3 RAM ディスク E、4 RAM ディスク F。

**備考**: ポケットディスクは 512 バイト、RAM ディスクは 256 バイト単位で使われる。

### END

**機能**: プログラムの実行を終了する。

**書式**:

```basic
END
```

**引数**: なし。

**備考**: 開いているファイルはすべて閉じられる。

### EOF

**書式**:


**備考**: `RUN`、電源断、プログラム読込みでクリアされる。

### ERN

**機能**: 直前に起きたエラーのコード番号を返す。

**書式**:

```basic
ERN
```

**引数**: なし。

**備考**: `ON ERROR GOTO` のエラー処理内で `ERL` と組み合わせて使う。

```basic
10 ON ERROR GOTO 100
20 FOR N=1 TO 20
30 READ A
40 PRINT A
50 NEXT N
60 END
100 IF ERL=30 AND ERN=53 THEN PRINT "NO DATA"
```

### IF ... THEN ... ELSE

**書式**:


**引数**:

- **条件**: `=`、`<>`、`<`、`>`、`<=`、`>=` を使った関係式。文字列は文字コードで比較する。複数の条件は `AND` / `OR`（または `*` / `+`）でつなぐ。

**備考**: 変数名の直後に `THEN` が続くときは間に空白を入れる（`IF A=B THEN`）。詳細は「命令詳細: 制御構文」の項。

### INIT

**機能**: RAM ディスク（E:, F:）またはポケットディスクを初期化する。

**書式**:

```basic

INIT "d:"
```

**引数**:

- **`d:`**: `X:`、`E:`、`F:`。
- **サイズ**: RAM ディスクのデータファイル領域を KB 単位で指定。E: は 2--27、F: は 2--(RAM カード容量 - 1)。`0K` を指定すると領域定義を解除。

**備考**: 実行時に既存内容を消してよいか確認される（`Y` / `N`）。ポケットディスクは両面あり、裏面は裏返して再度 `INIT "X:"`。

**引数**: なし。

**備考**: `SHIFT` / `CAPS` 自体を読むので、それに続く記号キーは読めない。

**引数**:

**備考**: `LOCATE` で表示位置を指定できる。

**引数**:

**備考**: ポケットディスク（`X:`）のファイルには使えない。数値も文字として読む。

**備考**: 区切りは `,`、CR、LF、CR+LF（数値は空白でも可）。`"` で始まるデータは次の `"` まで 1 項目。

### LINE

**機能**: 画面上の 2 点間に直線を引く。オプションで矩形も描ける。

**書式**:

```basic
LINE [(式1, 式2)] - (式3, 式4) [,式5] [,{S | R | X}] [,{B | BF}]
```

**引数**:

- **式1, 式2**: 始点。省略時は原点 (0,0) または前回の `LINE` の終点。
- **式3, 式4**: 終点。X は 0--239、Y は 0--31（範囲外は画面内の部分だけ描く）。
- **式5**: 線種。16 bit のビットパターン（0--65535）。省略時または `&HFFFF` で実線、`&H6666` などで点線。
- **S / R / X**: ドットをセット / リセット / 反転。省略時は S。
- **B / BF**: 2 点を対角とする矩形の枠 / 塗りつぶし。

```basic
10 CLS
20 LINE (10,0)-(239,16)
30 LINE (24,0)-(124,31),&HF18F,B
```

### LLINE

**機能**: プリンタ（CE-515P）で 2 点間に線を引く。`B` を付けると矩形。座標は `SORGN` の原点基準。

**書式**:


**引数**:

- **式1, 式2**: 始点。省略時は現在のペン位置（矩形のときは省略不可）。
- **式3, 式4**: 終点。
- **式5**: 線種（0--15）。省略時は 0（実線）。
- **式6**: 色（0--3）。省略時は前回の値。
- **B**: 2 点を対角とする矩形を描く。

**備考**: `LLINE (x1,y1)-(x2,y2)-(x3,y3)-...` と点を最大 6 個つなげて折れ線を描く形もある。

- **`d:`**: `X:`、`E:`、`F:`、`CAS:`。

- **#ファイル番号**: 以後の `INPUT#` / `PRINT#` / `CLOSE` で使う番号。
- **通信条件**: 例 `"COM:1200,N,8,1,A,C,&H1A,N,S"`。省略した項目は現在値を保持。

**備考**: 引数なしの書式 3 は前回の条件のままシリアルを開く（ファイル番号 1）。既に開いている番号を再度開くとエラー。`INPUT` / `APPEND` でファイルが無いとエラー。

### OPEN$

**機能**: 現在設定されているシリアル I/O の通信条件を文字列で返す。

**書式**:

```basic
OPEN$
```

**引数**: なし。

### PAINT

**機能**: プリンタ（CE-515P）で `LLINE` / `RLINE` の `B` オプションで描いた矩形の内側を網掛けする。

**書式**:

```basic
PAINT 式1 [,式2]
```

**引数**:

- **式1**: 網掛けパターン（0--10）。
- **式2**: 色（0--3）。

### PASS

**機能**: メモリ上のプログラムにパスワードを設定または解除する。

**書式**:

```basic
PASS "文字列"
```

**引数**:

- **文字列**: パスワード。同じ文字列で再度実行すると解除。

**備考**: 設定中は `LIST`、`DELETE`、変更、`BASIC` / `TEXT` などができない。`PASS` の後に他の文を続けるとエラーになり解除できない。プログラムが無い状態で実行するとエラー。

### PAUSE

**機能**: `PRINT` と同じように表示した後、約 0.85 秒待ってから次へ進む。

**書式**:

```basic
PAUSE {式 | 文字列} [{, | ;} {式 | 文字列}] ...
PAUSE USING "書式"; ...
PAUSE
```

**引数**:

- `PRINT` と同じ。

**備考**: 他機種との互換のために用意された命令。できるだけ `PRINT` と `WAIT` に置き換える。

### PEEK

**機能**: 指定番地のメモリ内容（1 バイト、0--255）を返す。

**書式**:

```basic
PEEK 番地
```

**引数**:

### POINT

**機能**: 画面上の指定ドットの状態を返す。

**書式**:

```basic
POINT (式1, 式2)
```

**引数**:

- **式1**: X 座標（0--239）。
- **式2**: Y 座標（0--31）。

**備考**: 点灯なら 1、消灯なら 0。

### POKE

**機能**: 指定番地からメモリに値を書き込む。

**書式**:

```basic
POKE 番地, 値 [,値, ...]
```

**引数**:

- **番地**: 書込み開始番地。
- **値**: 0--255。複数書くと連続番地に順に書く。


### PRESET

**機能**: 画面上の指定ドットを消す。

**書式**:

```basic
PRESET (式1, 式2)
```

**引数**:

- **式1, 式2**: X（0--239）、Y（0--31）座標。範囲外（-32768--32767）は無視される。

### PRINT

**機能**: 式や文字列を画面に表示する。

**書式**:

```basic
PRINT {式 | 文字列} [, {式 | 文字列}] ... [,]
PRINT {式 | 文字列} [; {式 | 文字列}] ... [;]
PRINT USING "書式"; {式 | 文字列} [{, | ;} ...]
PRINT
```

**引数**:

- **式 / 文字列**: 表示する項目。単独の数値は右詰め、文字列は左詰め。
- **`,`**: 単精度なら 13 桁ごとの欄に分けて表示。倍精度は 1 行に 1 項目。
- **`;`**: 左端から詰めて表示。
- **末尾の `,` / `;`**: 次の `PRINT` が続きから表示する。
- **書式**: `USING` の書式文字列。1 つの `PRINT` に 1 回だけ。
- 引数なし: 直前の表示を保持する（`WAIT` と組み合わせて使う）。

**備考**: 表示後の待ち時間は `WAIT` で決まる。`LOCATE` で開始位置を指定できる。`PRINT=LPRINT` を実行すると以後の `PRINT` がプリンタ出力になる。

```basic
10 A=1234: B#=5#/9: C$="ABCDE"
20 PRINT "A=";A
30 PRINT "EFGH";B#;C$;A
```

### PRINT#

**機能**: 開いたファイルに変数や式の値を書き込む。

**書式**:

```basic
PRINT# ファイル番号, {式 | 文字列} [{, | ;} {式 | 文字列}] ... [{, | ;}]
```

**引数**:

- **ファイル番号**: `OPEN ... FOR OUTPUT` / `APPEND` で開いた番号。
- **式 / 文字列**: 書き込む項目。末尾に `,` `;` が無いと CR+LF を付ける。

**備考**: 文字列を続けて書くときは `PRINT#2,"ABC";A$` のように区切らないと境界が分からなくなる。1 項目ずつ書くか、間に `","` を挟む。

### PSET

**機能**: 画面上の指定ドットを点灯（または消灯）する。

**書式**:

```basic
PSET (式1, 式2)
PSET (式1, 式2), X
```

**引数**:

- **式1, 式2**: X（0--239）、Y（0--31）座標。
- **`,X`**: 点灯していれば消し、消えていれば点ける（反転）。

### RADIAN

**機能**: 三角関数の角度単位をラジアンにする。

**書式**:

```basic
RADIAN
```

**引数**: なし。

### RANDOMIZE

**機能**: `RND` の乱数の種を変更する。

**書式**:

```basic
RANDOMIZE
```

**引数**: なし。

**備考**: 電源投入時の種は毎回同じなので、実行しないと `RND` は同じ系列を返す。

### READ

**機能**: `DATA` 文の値を順番に読み出して変数に代入する。

**書式**:

```basic
READ 変数, 変数, ..., 変数
```

**引数**:

- **変数**: 代入先。`DATA` の値と型を合わせる。

**備考**: 読み出し位置は `RESTORE` で戻せる。データが尽きるとエラー（ERN 53）。

### REM / '

**機能**: コメントを書く。行末まで実行に影響しない。

**書式**:

```basic
REM コメント
' コメント
```

**引数**:

- **コメント**: 任意の文字列。

### RENUM

**機能**: プログラムの行番号を付け直す。`GOTO` などの参照先も書き換える。

**書式**:

```basic
RENUM [新行番号] [,[旧行番号] [,増分]]
```

**引数**:

- **新行番号**: 付け直し後の最初の行番号。省略時は 10。
- **旧行番号**: 付け直しを始める現在の行番号。省略時は先頭。
- **増分**: 省略時は 10。

**備考**: 行番号が 65279 を超えるとエラー。`*` 表示中は `BREAK` で中断できる（`**` 表示中は不可）。エラーや中断時はプログラムは変わらない。

### RESTORE

**機能**: `READ` の読み出し位置を `DATA` 文の先頭または指定行へ戻す。

**書式**:

```basic
RESTORE {行番号 | *ラベル}
RESTORE
```

**引数**:

- **行番号 / `*ラベル`**: 次に読む `DATA` 文の行。省略時は最初の `DATA` 文。

### RESUME

**機能**: エラー処理ルーチンを終えて、プログラムの実行に戻る。

**書式**:

```basic
RESUME
RESUME NEXT
RESUME {行番号 | *ラベル}
```

**引数**:

- 引数なし: エラーを起こした文から再実行。
- **NEXT**: エラーを起こした文の次から再開。
- **行番号 / `*ラベル`**: 指定行から再開。

### RIGHT$

**機能**: 文字列の右端から N 文字を取り出す。

**書式**:

```basic
RIGHT$ (文字列, N)
```

**引数**:

- **文字列**: 元の文字列。
- **N**: 取り出す文字数。

### RLINE

**機能**: プリンタ（CE-515P）で、現在のペン位置を原点とする相対座標で線を引く。

**書式**:

```basic
RLINE (式1, 式2) - (式3, 式4) [,式5] [,式6] [,B]
```

**引数**:

- `LLINE` と同じ。ただし (式1, 式2) は省略できない。

### RND

**機能**: 乱数を返す。

**書式**:

```basic
RND 式
```

**引数**:

- **式**: 1 未満（例 0.5）なら 0 以上 1 未満の実数。1 以上の整数 n なら 1 以上 n 以下の整数。

### RUN

**機能**: メモリ上のプログラムを実行する。変数はクリアされる。

**書式**:

```basic
RUN [{行番号 | *ラベル}]
```

**引数**:

- **行番号 / `*ラベル`**: 開始位置。省略時は先頭。

### SAVE

**機能**: メモリ上の BASIC プログラムをデバイスに保存する。

**書式**:

```basic
SAVE ["d:ファイル名" [,A]]
SAVE M "d:ファイル名", 開始番地, 終了番地
```

**引数**:

- **`"d:ファイル名"`**: `d:` は `X:`、`E:`、`F:`、`CAS:`、`COM:`。拡張子省略時は `.BAS`（3 文字まで）。
- **`,A`**: ASCII 形式で保存。省略時は中間コード。
- **`SAVE M`**: 開始番地から終了番地までのメモリ内容（機械語）を保存。

**備考**: 同名ファイルは上書きされるが、`P` 属性なら エラー。パスワード設定中のプログラムはエラー。`CAS:` / `COM:` は ASCII 形式のみ。

### SET

**機能**: ファイルの書込み禁止属性を設定・解除する。

**書式**:

```basic
SET "d:ファイル名", "P"
SET "d:ファイル名", " "
```

**引数**:

- **`"d:ファイル名"`**: `d:` は `X:`、`E:`、`F:`。ワイルドカード可、拡張子は省略しない。
- **`"P"`**: 書込み・削除・改名を禁止。**`" "`**（空白）で解除。

**備考**: 開いているファイルに対して実行するとエラー。

### SORGN

**機能**: プリンタ（CE-515P）の現在のペン位置を座標の原点にする。

**書式**:

```basic
SORGN
```

**引数**: なし。

### STOP

**機能**: プログラムの実行を一時停止し、`Break in 行番号` を表示する。`CONT` で再開できる。

**書式**:

```basic
STOP
```

**引数**: なし。

### STR$

**機能**: 数値を文字列に変換する。

**書式**:

**引数**:

- **式**: 変換する数値。

### TEXT

**機能**: TEXT モードに入る。プログラムを文字列として扱い、他機種のプログラム入力やシリアル送信に使う。プロンプトが `<` になる。

**書式**:

```basic
TEXT
```

**引数**: なし。

**備考**: PRO モードの直接入力でだけ有効。パスワード設定中はエラー。`BASIC` で戻る。

### TRON / TROFF

**機能**: `TRON` は実行中の行番号を表示するトレースモードを開始し、`TROFF` で終了する。

**書式**:

```basic
TRON
TROFF
```

**引数**: なし。

### USING

**機能**: `PRINT` / `LPRINT` / `PAUSE` で表示・印字する数値や文字列の書式を指定する。

**書式**:

```basic
USING "書式文字列"
USING
```

**引数**:

- **書式文字列**: `#` 数字（右詰め、整数部は符号込み 2--21 桁、小数部 0--20 桁）、`.` 小数点、`,` 3 桁区切り、`^` 指数表示、`&` 文字（左詰め）。例: `"###.##"`、`"&&&&&&"`。
- 引数なし: 書式を解除する。

**備考**: `PRINT USING "書式"; 式` のように 1 文の中だけで使う形もある。

### VAL

**機能**: 数字の文字列を数値に変換する。

**書式**:

```basic
VAL 文字列
```

**引数**:

- **文字列**: 10 進数（符号・小数点可）または `&H` 付き 16 進数。式（`"3.2*4"`）も評価される。不正な文字があるとそこまでを変換する。制御コード（`&H00`--`&H1F`）は不可。

### WAIT

**機能**: `PRINT` / `GPRINT` の表示後、次の文へ進むまでの待ち時間を設定する。

**書式**:

```basic
WAIT 式
WAIT
```

**引数**:

- **式**: 0--65535。1 が約 1/59 秒。電源投入時は 0（待たない）。
- 引数なし: 無限に待つ（キー入力または `CONT` で続行）。

**備考**: プログラム中のすべての `PRINT` / `GPRINT` に効く。

| `FACT x` | 階乗。 |
| `HCS x` | 双曲線余弦。 |
| `HEX x` | 10 進値を 16 進に変換。S。文字列で欲しいときは `HEX$`。 |
| `HSN x` | 双曲線正弦。 |

## ROM 8.5 拡張（構造化 BASIC）

以下は PC-E500 操作説明書には無く、この ROM の拡張領域（`30000h` 台）で処理されるキーワードである。書式は PC-E650 の構造化 BASIC に基づく。

### WHILE ... WEND

**機能**: 条件が真のあいだ、囲まれた文を繰り返す。条件は先頭で判定する。

**書式**:

```basic
WHILE 条件
  ...
WEND
```

### REPEAT ... UNTIL

**機能**: 囲まれた文を実行してから条件を判定し、偽のあいだ繰り返す（最低 1 回実行）。

**書式**:

```basic
REPEAT
  ...
UNTIL 条件
```

**備考**: `UNTIL` が対応する `REPEAT` を持たないとエラー 3Eh「UNTIL without REPEAT」。

### SWITCH ... CASE ... DEFAULT ... ENDSWITCH

**機能**: 式の値に一致する `CASE` の文を実行する。どれにも一致しなければ `DEFAULT` を実行する。

**書式**:

```basic
SWITCH 式
CASE 値1
  ...
CASE 値2
  ...
DEFAULT
  ...
ENDSWITCH
```

### IF ... THEN / ELSE / ENDIF（ブロック形式）

**機能**: `THEN` の後に何も書かないと複数行にわたるブロック `IF` になり、`ENDIF` で閉じる。

**書式**:

```basic
IF 条件 THEN
  ...
ELSE
  ...
ENDIF
```

### EVAL

**機能**: 文字列に書かれた式を評価して値を返す。

**書式**:

```basic
EVAL 文字列
```

**引数**:

- **文字列**: `"A*2+1"` のような式を含む文字列。

- キーワード名、token、処理レコード、入口は ROM 8.5 の固定表を抽出したもの。抽出結果はこの表にまとめている。
- 中間コードの基本表現と BASIC の内部データの説明は Sharp *Technical Reference Manual PC-E500* の BASIC 中間コード・内部表現の節を参照した。ここでは ROM で再確認できる事実だけを確定値としている。
